# Catalog image provenance

The public asset directory contains 30 generated photographs of a consistent fictional slim male model, on a neutral grey seamless studio backdrop, wearing the 30 complete outfits in data.js. No brand logos or text. Each is an individual 800×1200 WebP.

The owner’s separate 30-look personal catalog was generated from his supplied photographs and latest accepted face/body references. Those images and their reference assets live only in the private server checkout, never in this public static bundle. The server requires verified Firebase authorization before returning personal pixels.
